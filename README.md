# Ernest Mpiani — Portfolio v2

Personal portfolio. React 18 + Vite + React Router v6.
Design: Editorial brutalism. Black & grey only. DM Serif Display + DM Mono + DM Sans.

## Quick Start

```bash
npm install
npm run dev
# → http://localhost:5173
```

## Before deploying

1. Open `src/data.js` and update your real email, GitHub, LinkedIn URLs
2. Replace `"YOUR_FORMSPREE_ID"` with your actual Formspree form ID (free at formspree.io)
3. Deploy to Vercel — `vercel.json` handles SPA routing automatically

## Build

```bash
npm run build   # outputs to dist/
```
